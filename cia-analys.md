# CIA-analys av hotet: Nätfiske (Phishing)

**Valt hot:** En angripare kommer åt ett Microsoft 365-konto via nätfiske.

* **Konfidentialitet (Confidentiality):** **PÅVERKAS.** Angriparen kan läsa känslig e-post, dokument och personuppgifter som kontot har behörighet till.
* **Integritet (Integrity):** **PÅVERKAS.** Angriparen kan ändra i filer, skicka falska mejl i användarens namn eller radera viktig information.
* **Tillgänglighet (Availability):** **MINDRE PÅVERKAD / PÅVERKAS.** Om angriparen byter lösenordet blir den behöriga användaren utelåst från sitt konto och kan inte utföra sitt arbete.
